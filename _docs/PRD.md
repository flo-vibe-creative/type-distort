# Type Distort — 타이포그래피 왜곡 툴

작성일: 2026-09-07

## 1. 한 줄 요약

미리 만들어 온 글자(SVG·PNG)를 가져와 아크·메쉬·퍼스펙티브·볼록 왜곡을 직접 조작해 만들고, PNG·JPEG·SVG로 내보내는 브라우저 기반 디자인 툴.

## 2. 배경과 목적

Apple, Spotify, Nike 류의 캠페인 그래픽에서 자주 보이는 "휘고 늘어난 타이포"는 현재 애프터이펙트나 일러스트레이터에서 매번 수작업으로 만든다. 만들 때마다 값을 다시 잡아야 하고, 미세 조정이 느리다.

이 툴의 목적은 **왜곡 자체를 슬라이더와 핸들로 실시간 제어**해서, 시안 탐색 속도를 끌어올리는 것이다. 완성된 글자를 가져와 왜곡만 담당하며, 글자를 만드는 기능(폰트 선택, 자간 조정 등)은 범위 밖이다.

## 3. 사용자와 사용 흐름

대상: 디자이너 및 비개발자 콘텐츠 제작자.

```
일러스트/피그마에서 글자를 윤곽선으로 변환해 SVG 저장
  → Type Distort에 끌어다 놓기 (여러 개 가능)
  → 레이어별로 위치·크기·회전 배치
  → 레이어별로 왜곡 효과 선택 + 핸들/슬라이더로 조정
  → PNG / JPEG / SVG 로 내보내기
```

## 4. 범위

### 포함 (1차 버전)

| 영역 | 내용 |
| --- | --- |
| 가져오기 | SVG(벡터), PNG·JPEG(이미지). 파일 선택 + 캔버스 드래그&드롭, 다중 선택 |
| 레이어 | 여러 파일을 한 작업 안에 올려 개별 편집. 선택·순서 변경·숨김·삭제 |
| 배치 | 레이어별 위치·크기·회전. 캔버스에서 직접 드래그 (피그마 방식) |
| 왜곡 | 아크/링, 자유 메쉬, 퍼스펙티브, 볼록·웨이브 — 레이어당 1개 |
| 자간 | 모든 효과에 공통으로 걸리는 글자 사이 간격 조절 (벡터 레이어 전용) |
| 내보내기 | PNG(1x/2x/4x, 투명 옵션), JPEG(품질·배경색), SVG(벡터 유지) |
| 배경 | 캔버스 배경색과 배경 이미지 (채우기·맞추기·늘이기) |
| 색 | 레이어별 글자 색 덮어쓰기 (벡터 레이어 전용) |
| 편의 | 되돌리기/다시하기, 브라우저 자동 저장, 내용에 맞춰 자르기 |

### 제외 (1차 버전에서 하지 않음)

- 툴 안에서 글자를 직접 타이핑 / 폰트 선택
- 레이어 하나에 왜곡 효과 여러 개 겹치기 (데이터 구조는 확장 가능하게 열어둠)
- 애니메이션 / 동영상 내보내기
- 서버 저장, 계정, 협업, 공유 링크
- 색상·그라디언트 편집 (원본 SVG의 색은 유지만 함)

## 5. 기능 상세

### 5.1 화면 구성

```
┌──────────────────────────────────────────────────────────────┐
│  [+ 가져오기]   type distort            [내보내기 ▾]          │  상단 바
├────────────┬─────────────────────────────────┬───────────────┤
│  레이어     │                                 │  설정 패널     │
│            │                                 │               │
│ ▸ WOW.svg  │        ┌───────────────┐        │ 효과: 아크 ▾   │
│ ▸ beat.svg │        │  W O W !      │        │ ───────────── │
│ ▸ bg.png   │        │  (핸들 표시)    │        │ 각도  ●────   │
│            │        └───────────────┘        │ 반지름 ──●──   │
│ [순서 ↑↓]   │                                 │ 세기  ─●───   │
│ [숨김/삭제] │      (휠=확대, 스페이스=이동)      │ [초기화]      │
└────────────┴─────────────────────────────────┴───────────────┘
```

- **왼쪽 — 레이어 목록**: 가져온 파일이 하나씩 쌓인다. 파일 종류(벡터/이미지)를 아이콘으로 구분해, 어떤 레이어가 SVG로 저장 가능한지 즉시 알 수 있게 한다.
- **가운데 — 캔버스**: 휠로 확대/축소, 스페이스+드래그로 이동. 선택된 레이어에만 핸들이 표시된다.
- **오른쪽 — 설정 패널**: `배치` 탭과 `왜곡` 탭. 핸들을 드래그하면 슬라이더 값이 따라 움직이고, 슬라이더를 움직이면 핸들이 따라 움직인다 (양방향 동기화).

### 5.2 배치 (transform)

왜곡과 독립적인 레이어별 위치·크기·회전 값.

- 캔버스에서 레이어 클릭 → 선택, 그대로 드래그 → 이동 (모드 전환 없이 바로)
- 크기와 회전은 캔버스의 선택 상자 핸들로만 조절한다 (숫자 입력칸은 두지 않는다)
- 바운딩 박스 모서리 드래그 → 크기 조절, 모서리 바깥 → 회전
- `Shift` + 이동 = 수평/수직 고정, `Shift` + 크기 조절 = 비율 유지
- 방향키 = 1px 이동, `Shift` + 방향키 = 10px 이동
- 겹친 레이어는 레이어 패널 순서상 위쪽 것이 먼저 선택된다
- 배치는 왜곡 결과에 곱해지는 형태이므로, 왜곡을 마친 뒤 위치를 옮겨도 왜곡 모양은 변하지 않는다

**여러 레이어 고르기.** 빈 곳에서 드래그하면 사각형이 그려지고 거기 걸친 레이어들이 골라진다. `Shift` + 클릭으로 하나씩 더하거나 뺄 수도 있다. 여러 개를 골라 두면 함께 옮길 수 있고, 골라 둔 것 중 하나를 끌지 않고 그냥 누르면 그 하나만 남는다. 크기 조절과 회전은 기준이 하나여야 하므로 한 개만 골랐을 때 쓸 수 있다.

### 5.3 배치와 왜곡을 한 화면에서

모드를 나누지 않는다. 레이어를 한 번 클릭하면 곧바로 옮길 수 있고, 왜곡 조작점도 함께 보인다.

| 표시 | 언제 | 모양 |
| --- | --- | --- |
| 선택 상자 | 레이어를 고르면 | 파란 사각형 + 크기·회전 핸들 (한 개만 골랐을 때) |
| 여러 개 선택 | 두 개 이상 고르면 | 개별 파란 사각형 + 전체를 감싸는 점선 |
| 왜곡 조작점 | 한 개만 골랐을 때 | 보라색 점 |
| 점 편집 | 레이어를 더블클릭하면 | 선택 상자가 숨고 조작점만 남는다 |

선택 상자는 글자에서 화면 기준 9px 띄워 그린다. 메쉬 격자점이 모서리에 딱 붙어 있어도 크기 조절 핸들과 겹치지 않게 하려는 여유다. 왜곡 조작점은 선택 상자 위에 그려 먼저 잡힌다.

`Esc`는 한 단계씩 빠져나온다 — 골라 둔 조작점 → 점 편집 → 레이어 선택 순서다.

### 5.4 왜곡 효과

| 효과 | 설명 | 캔버스 핸들 | 슬라이더 |
| --- | --- | --- | --- |
| 아크 / 링 | 글자를 원호 경로를 따라 휘게 함 | 호 곡선 + 양 끝점 + 기준선 점 | 각도, 기준선, 세기 |
| 자유 메쉬 | 4×4 격자의 점 16개를 자유롭게 이동 | 격자점 16개 (여러 개 선택 가능) | (핸들 전용, 격자는 4×4 고정) |
| 퍼스펙티브 | 네 모서리를 잡아당겨 3D 원근 생성 | 모서리 4개 (여러 개 선택 가능) | (핸들 전용) |
| 볼록 / 웨이브 | 중심 기준으로 부풀리거나 파도치게 함 | 중심점 + 반경 원 | 세기, 반경, 파동 수 (0이면 순수 볼록) |

### 5.4.1 자간

효과 종류와 상관없이 모든 왜곡에 함께 걸리는 값으로, 왜곡을 적용하기 **전에** 글자 사이를 벌리거나 좁힌다. 벌린 만큼 왜곡의 기준 영역도 함께 넓어지므로, 자간을 바꿔도 왜곡이 글자 전체에 고르게 걸린다.

- 값은 글자 높이에 대한 비율(%)이며 0%이면 원본 그대로. 음수는 좁아진다
- 첫 글자는 제자리에 남고 뒤 글자만 오른쪽으로 밀린다
- 글자가 서로를 지나칠 만큼 좁혀지지는 않도록 제한한다

**글자를 나누는 방법.** 가져온 SVG에는 "여기까지가 한 글자"라는 정보가 없다. 그래서 가로로 겹치는 도형 덩어리를 한 글자로 본다. `O`의 구멍처럼 바깥선 안에 든 것은 자연히 같은 글자로 묶이고, 나란히 떨어진 글자들은 따로 나뉜다. 몇 개로 나뉘었는지 패널에 표시해 사용자가 확인할 수 있게 한다.

### 5.4.2 조작점 여러 개 고르기

메쉬의 격자점과 퍼스펙티브의 모서리처럼 "그 자리 자체"가 값인 조작점은 여러 개를 한꺼번에 골라 함께 옮길 수 있다. 피그마와 같은 방식이다.

점을 여러 개 감싸서 고르는 드래그는 레이어를 옮기는 드래그와 자리가 겹친다. 그래서 **점 편집**이라는 얕은 상태를 둔다. 레이어를 더블클릭하면 들어가고, 그 동안에는 레이어가 움직이지 않아 캔버스 어디서 끌든 점을 감쌀 수 있다. 탭이 생기는 것은 아니며 설정 패널은 그대로 하나다.

| 조작 | 동작 |
| --- | --- |
| 레이어 더블클릭 | 점 편집에 들어간다 (선택 상자가 숨는다) |
| 점 편집 중 아무 곳에서나 드래그 | 사각형을 그려 그 안에 든 점을 모두 고른다 |
| 격자의 가로줄·세로줄 클릭 | 그 줄의 네 점이 통째로 골라진다 (메쉬) |
| 점 클릭 | 그 점 하나만 고른다 |
| `Shift` + 위 조작들 | 골라 둔 것에 더한다. 이미 골라 둔 점을 다시 누르면 뺀다 |
| 골라 둔 점 중 하나를 드래그 | 고른 점 전부가 같은 거리만큼 함께 움직인다 |
| 글자 바깥 빈 곳 클릭 | 점 편집에서 나간다 |
| 글자 위 클릭 (점이 아닌 곳) | 골라 둔 점만 놓아준다. 편집은 이어간다 |
| `Esc` | 위와 같은 순서로 한 단계씩 빠져나온다 |

골라 둔 점은 채워진 원으로 크게 그려 구분한다. 아크의 끝점(각도)이나 볼록의 반경 점은 각자 다른 뜻을 가진 조절점이라 묶이지 않는다.

### 5.4.3 배경과 글자 색

**배경.** 레이어를 아무것도 고르지 않으면 설정 패널에 캔버스 배경이 나온다. 피그마의 보드 Fill과 같은 자리다.

- **배경색**: 색을 고른다
- **투명하게**: 켜면 배경색과 배경 이미지가 모두 감춰져 투명해진다. 골라 둔 값은 그대로 남아 있어 체크를 풀면 곧바로 돌아온다
- **배경 이미지**: PNG·JPEG를 골라 배경색 위에 깐다. `채우기`(꽉 채우고 넘치면 자름) / `맞추기`(전체가 보이게 넣고 남는 곳은 배경색) / `늘이기`(비율 무시하고 정확히 맞춤) 중에 고른다
- 이미지 원본도 함께 저장해 새로고침 후 되살아난다

**글자 색.** 레이어를 고르면 `색` 항목에서 글자 색을 덮어쓸 수 있다. 기본은 가져온 SVG의 색을 그대로 쓰는 상태이고, 색을 고르면 그 레이어의 모든 도형이 그 색으로 칠해진다. `원래 색으로 되돌리기`로 언제든 되돌린다. 이미지 레이어에는 쓰이지 않는다.

배경과 글자 색 모두 내보내기(SVG·PNG·JPEG)에 그대로 반영된다.

### 5.5 내보내기

| 형식 | 옵션 | 동작 |
| --- | --- | --- |
| SVG | — | 벡터 레이어는 왜곡된 실제 경로로 저장. 이미지 레이어가 섞여 있으면 해당 레이어만 비트맵으로 구워 `<image>`로 삽입하고, 저장 전 안내 |
| PNG | 배율 1x/2x/4x, 투명 배경 on/off | 캔버스 크기 × 배율로 렌더 |
| JPEG | 품질 슬라이더, 배경색 | 투명 불가 → 배경색 지정 필수 안내 |

- 내보낼 캔버스 크기는 상단에서 지정
- `내용에 맞춰 자르기` 버튼: 보이는 레이어 전체의 경계에 맞춰 캔버스 크기를 재조정
- 파일명은 첫 레이어 이름 기반으로 자동 제안

### 5.6 작업 내용 보존

Document 데이터를 브라우저 로컬 저장소에 자동 저장해, 실수로 새로고침하거나 탭을 닫아도 마지막 작업 상태로 복구된다. 가져온 이미지 원본도 함께 보관한다. 저장은 서버가 아닌 사용자 브라우저 안에서만 이루어진다.

## 6. 기술 설계

### 6.1 렌더링 — 하이브리드 방식

벡터 레이어는 브라우저의 SVG 렌더러로, 이미지 레이어는 WebGL 캔버스로 그려 겹친다.

- 화면에 보이는 SVG가 곧 내보내는 SVG이므로 **보이는 그대로 저장**된다
- 글자의 구멍(ㅇ, O, 8 안쪽) 처리와 안티에일리어싱을 브라우저에 맡길 수 있다
- 대안이었던 "전부 WebGL"은 경로 삼각분할 비용이 크고 화면/결과가 어긋날 수 있어 채택하지 않음
- 대안이었던 "전부 래스터"는 SVG 내보내기가 불가능해 요구사항과 충돌

### 6.2 왜곡 엔진 — 단일 좌표 변환 함수

네 효과 모두 아래 형태의 순수 함수 하나로 표현한다.

```
warp(정규화 좌표 (u, v), 파라미터) → 왜곡 좌표 (x, y)
```

- 아크: 삼각함수로 호를 따라 회전 배치. 반지름은 호의 길이가 원본 너비와 같아지도록 자동 계산해 글자가 늘어나지 않게 한다 (반지름을 따로 조절하면 각도와 역할이 겹쳐 혼란스러우므로 슬라이더에서 제외)
- 아크의 기준선: 글자의 어느 높이가 호 위에 올라앉을지 정한다. 0이면 윗변, 1이면 아랫변, 0.5면 한가운데. 아래로 내리면 글자가 곡선 위에 서고, 위로 올리면 매달린다. 글자 밖으로도 -0.5~1.5 범위까지 뺄 수 있다
- 볼록/웨이브: 중심으로부터의 거리에 따라 반경 방향으로 밀어냄
- 퍼스펙티브: 네 모서리로부터 구한 원근 변환 행렬 적용
- 메쉬: 격자 제어점 사이를 부드럽게 보간

이 함수를 두 파이프라인이 공유한다.

| 대상 | 처리 |
| --- | --- |
| 벡터 레이어 | 글자 외곽선의 곡선을 잘게 쪼개 점 수천 개로 만들고, 각 점을 warp에 통과시켜 새 경로를 생성. 쪼개는 정밀도는 화면 배율에 맞춰 자동 조절 |
| 이미지 레이어 | 이미지를 격자로 분할해 각 격자점을 warp에 통과시키고, GPU로 텍스처를 늘려 그림 |

효과를 하나 추가할 때 warp 함수 하나만 추가하면 두 종류 입력에 모두 적용된다.

### 6.3 데이터 구조

```
Document
├ canvas: { width, height, background, image, imageFit }
└ layers: [
    {
      id, name, visible,
      source: { kind: 'vector', paths: [...] } | { kind: 'raster', image: ... },
      transform: { x, y, scaleX, scaleY, rotation },
      letterSpacing,
      fillOverride,
      warp: { type: 'arc' | 'mesh' | 'perspective' | 'bulge', params: { ... } }
    }
  ]
```

`warp`는 향후 효과 스택 확장을 위해 배열로 감쌀 수 있는 형태로 설계한다.

### 6.4 성능

핸들 드래그 중에는 낮은 정밀도로 실시간 미리보기, 드래그를 놓으면 고정밀도로 다시 렌더한다.

### 6.5 되돌리기

`Cmd+Z` / `Cmd+Shift+Z`. Document 전체를 스냅샷으로 쌓는 방식으로 50단계 보관한다.
키를 누르고 있을 때 브라우저가 보내는 자동 반복은 무시해, 한 번 누름이 정확히 한 단계가 되게 한다.
드래그·슬라이더·색 고르기처럼 값이 계속 바뀌는 조작은 한 번의 조작을 한 단계로 묶는다.

### 6.6 기술 스택

Next.js(정적 빌드) + TypeScript + Tailwind CSS. 서버 런타임 없음. 모든 파일 처리는 브라우저 안에서만 이루어지며 외부로 전송되지 않는다.

## 7. 제약과 한계 (사용자에게 명시적으로 안내)

1. **SVG 안에 살아있는 텍스트(`<text>`)는 왜곡할 수 없다.** 폰트 정보가 파일에 없으면 브라우저가 다른 폰트로 대체해 결과가 달라지기 때문. 해당 레이어는 가져오지 않고 "글자를 윤곽선으로 변환(Create Outlines) 후 다시 저장해주세요"라고 안내한다.
2. **선(stroke)으로 그려진 글자는 선 두께가 왜곡을 따라가지 않고 일정하게 유지된다.** 면(fill)으로 된 글자를 권장한다.
3. **PNG로 가져온 레이어는 SVG로 내보내도 진짜 벡터가 되지 않는다.** 픽셀 이미지가 삽입된 형태가 된다.
4. 아주 큰 이미지는 그래픽 카드 텍스처 한계(4096px)에 맞춰 자동 축소된다.
5. **자간은 벡터 레이어에서만 쓸 수 있다.** 이미지 레이어에는 글자 단위 정보가 없다.
6. **글자끼리 가로로 겹쳐 있으면 한 글자로 묶인다.** 필기체나 자간이 아주 좁은 서체가 여기 해당한다. 패널에 표시되는 글자 수가 실제와 다르면 디자인 툴에서 자간을 조금 벌려 다시 내보내면 된다.

## 8. 에러 처리 원칙

모든 실패는 영문 원본 메시지 대신 `왜 이렇게 됐는지 → 어떻게 하면 되는지` 순서의 한국어 안내로 표시한다.

| 상황 | 안내 |
| --- | --- |
| SVG 파싱 실패 | 지원하지 않는 형식임을 알리고, 다시 저장하는 방법 안내 |
| `<text>` 포함 SVG | 윤곽선 변환 안내 |
| 지원하지 않는 파일 형식 | 지원 형식(SVG·PNG·JPEG) 안내 |
| 내용 없이 내보내기 시도 | 레이어를 먼저 추가하도록 안내 |
